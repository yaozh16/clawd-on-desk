# Clawd on Desk 项目深度分析报告

## 一、项目概述

### 1.1 项目定位

**Clawd on Desk** 是一款跨平台桌面宠物应用，以 Anthropic 官方吉祥物「Clawd」（像素风螃蟹）为形象，能够实时感知 AI 编程助手（Claude Code、Codex CLI、Copilot CLI）的工作状态并做出相应的动画反应。

这不是一个简单的娱乐应用，而是一个**人机交互创新项目**——它将 AI Agent 的抽象工作状态具象化为可爱的桌面角色行为，为开发者提供了一种全新的、情感化的 AI 辅助编程体验。

### 1.2 核心价值主张

```
传统模式：开发者盯着终端，等待 AI 响应
Clawd 模式：AI 的思考、工作、错误、完成都有视觉反馈
```

- **情感陪伴**：让孤独的编程过程有了「伙伴感」
- **状态可视化**：无需盯着终端，桌宠状态即 AI 状态
- **效率提升**：权限审批气泡、终端跳转等实用功能
- **交互创新**：眼球追踪、点击反应、睡眠序列等生命感设计

### 1.3 技术规格

| 维度 | 规格 |
|------|------|
| 平台 | Windows 11 + macOS |
| 运行时 | Electron 41.x |
| 动画系统 | SVG + CSS Keyframes |
| 通信机制 | 本地 HTTP Server (127.0.0.1:23333) |
| 支持的 Agent | Claude Code、Codex CLI、Copilot CLI |
| 安装包大小 | ~50MB (Windows NSIS) |
| 内存占用 | ~80-120MB |

### 1.4 项目成熟度

当前版本 **v0.5.0**，已完成以下里程碑：

```
MVP → 状态感知 → 交互打磨 → 生命感（眼球追踪/点击反应/睡眠序列）
→ macOS 适配 → GitHub 发布 → 终端定位 → 权限审批气泡 → 多 Agent 支持
```

项目已具备完整的工程化能力：
- 自动更新机制
- 国际化支持（中/英）
- VS Code/Cursor 扩展集成
- 系统托盘 + Do Not Disturb 模式
